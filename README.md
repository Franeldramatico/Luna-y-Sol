# 🌙 Luna y Sol

A beautiful astronomical eclipse visualization web application built with Angular. Features celestial canvas animations, star effects, heart rain, and an interactive solar eclipse.

![Luna y Sol](https://img.shields.io/badge/Luna%20y%20Sol-Eclipse%20Visualization-blue)

## 🚀 Features

- 🌌 Animated celestial canvas with twinkling stars
- 🌠 Graceful shooting stars
- ❤️ Heart rain effects
- 🌍 Interactive solar eclipse
- 🎵 Celestial ambient soundscape
- 🎨 Modern Material Design components

## 🎯 Getting Started

### Prerequisites

- Node.js 20.x or later
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Franeldramatico/Luna-y-Sol.git

# Navigate to the project directory
cd Luna-y-Sol

# Install dependencies
npm install
```

### Running Locally

```bash
# Start the development server
npm start
```

The application will be available at `http://localhost:3000`.

## 🏗️ Build

### Production Build

```bash
npm run build
```

The built files will be generated in the `dist/app/` directory.

### GitHub Pages Build

```bash
npm run build-gh
```

This command builds the app with the correct base href for GitHub Pages deployment.

## 🌐 Deployment

### GitHub Pages

This project is automatically deployed to GitHub Pages on every push to the `main` branch.

**Live Site:** https://Franeldramatico.github.io/Luna-y-Sol/

The deployment is handled by GitHub Actions using the `.github/workflows/deploy.yml` workflow.

### Manual Deployment

```bash
npm run predeploy
npm run deploy
```
