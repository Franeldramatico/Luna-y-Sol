# Luna y Sol

Astronomical eclipse visualization web application.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm start`

## Build for Production

```bash
npm run build
```

The output will be available in the `dist/app/` directory.

## GitHub Pages

This project is configured to deploy to GitHub Pages. The `gh-pages` branch contains the built site.
